# 👻 PhantomStalker

> **Твій фантом. Твої люди. Твій слід.**

PhantomStalker — термінальний застосунок-компаньйон з ШІ-персонажем: маленьким
оранжевим фантомом, який живе у твоєму терміналі й допомагає тобі спілкуватися з
людьми, тримати стосунки в порядку й стежити за *власним* цифровим слідом —
тепло, стильно й приватно.

```
┌─ PhantomStalker ─────────[1] Чат [2] Люди [3] Слід [4] Коуч─┐
│     . . .    │ Твоя чернетка або отримане повідомлення:     │
│    .---.     │ ┌──────────────────────────────────────────┐ │
│   ( o O )    │ │ привіт, вибач що довго мовчу, на каву?   │ │
│   |  ~  |    │ └──────────────────────────────────────────┘ │
│   |     |    │ [Відполірувати] [Тепліше] [Формальніше] …    │
│   '^'^'^'    │ Результат:                                   │
│  Phantom     │ ┌──────────────────────────────────────────┐ │
│  [thinking]  │ │ Привіт! Вибач, що так довго мовчу …      │ │
│              │ └──────────────────────────────────────────┘ │
├──────────────┴──────────────────────────────────────────────┤
│ / команда   ↹ модуль   ? довідка   s налаштування   q вихід │
└─────────────────────────────────────────────────────────────┘
```

## Можливості (MVP v0.1)

| Модуль | Що вміє |
|---|---|
| **Фантом** | ASCII-персонаж зі станами `idle` · `thinking` · `happy` · `alert` · `sleeping`, легка анімація, короткі репліки, засинає без активності й прокидається від натискання клавіш. Ім'я змінюється в налаштуваннях. |
| **[1] Чат — напарник-листування** | Полірує чернетку, робить тепліше / формальніше / коротше, перекладає, пропонує відповідь на отримане повідомлення — *твоїм* голосом. Відповідь стрімиться з Claude API в реальному часі. Результати можна зберегти як чернетки. |
| **[2] Люди — особиста CRM** | Ручне додавання людей: нік, теги, нотатки, важливі дати (з щорічним повтором), «востаннє спілкувались», історія розмов, пошук. Фантом нагадує про найближчі дати й про тих, з ким давно не було зв'язку. |
| **Налаштування** | Ключ API — у системному **keyring**, профіль тону, ім'я фантома, мова перекладу, модель, поріг нагадувань. |
| [3] Слід, [4] Коуч | Заглушки — з'являться у v0.2 / v0.3. |

## Встановлення

Потрібен Python 3.11+.

```bash
cd PhantomStalker
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
```

## Ключ API

Отримай ключ на [platform.claude.com](https://platform.claude.com/) і обери один спосіб:

1. **Рекомендовано:** запусти застосунок, натисни `s` і встав ключ — він збережеться
   в системному keyring (macOS Keychain, Windows Credential Locker, Secret Service у Linux).
2. Або скопіюй `.env.example` у `.env` і впиши `ANTHROPIC_API_KEY=...`
   (зручно на серверах без keyring). `.env` вже в `.gitignore`.

Порядок пошуку ключа: keyring → змінна середовища `ANTHROPIC_API_KEY`.

## Запуск

```bash
phantomstalker              # або: python -m phantomstalker
phantomstalker --db ./my.db # інша база
```

База за замовчуванням: `~/.phantomstalker/phantom.db` (або `$PHANTOMSTALKER_DB`).

### Гарячі клавіші

| Клавіша | Дія |
|---|---|
| `1`–`4` / `Tab` | перемкнути модуль (у полях вводу `Tab` переходить між полями) |
| `/` | командна палітра |
| `s` | налаштування |
| `?` | довідка |
| `Esc` | назад / зняти фокус з поля |
| `q` | вихід |
| **Люди:** `a` / `e` / `c` / `d` / `Del` | додати / редагувати / «спілкувались сьогодні» / важлива дата / видалити |

## Архітектура

```
UI (Textual: екрани, віджети)
 └─ Core (рушій персонажа PersonaEngine, роутинг модулів у App)
     └─ Services (CopilotService → Claude API, CRMRepository, SettingsService)
         └─ Storage (SQLite + keyring)
```

Потік: дія користувача → App → потрібний сервіс → оновлення стану → ререндер UI + реакція фантома.

```
src/phantomstalker/
├── __main__.py            # CLI-вхід
├── app.py                 # головний Textual-застосунок, гарячі клавіші, палітра
├── core/persona.py        # настрої, ASCII-кадри, кольори, репліки, цикл анімації
├── services/
│   ├── copilot.py         # промпти + стрімінг через anthropic SDK
│   ├── crm.py             # контакти, взаємодії, важливі дати, нагадування, чернетки
│   └── settings.py        # налаштування в SQLite, ключ API в keyring, .env
├── storage/db.py          # схема SQLite
└── ui/                    # панель фантома, модулі «Чат» і «Люди», форми, налаштування
```

**Таблиці БД:** `contacts`, `interactions`, `important_dates`, `drafts`,
`footprint_checks` (лише self, зберігається хеш), `settings`, `persona_state`.

### Claude API

Ко-пілот використовує офіційний `anthropic` SDK зі стрімінгом і моделлю
`claude-opus-5-5` (можна змінити в налаштуваннях). Для швидкості переписування
працює з `effort: low`. Увімкнено серверний fallback (`fallbacks: "default"`):
якщо модель відхилить запит, API саме перезапустить його на відповідній моделі.
Якщо відмова все ж трапилась — фантом переходить у стан `alert` і повідомляє про це.

## Приватність і етичні межі

**Усе локально.** База живе на твоїй машині; назовні йде лише текст, який ти
свідомо надсилаєш у Claude API. Ключ API — у keyring, а не в коді чи базі.

PhantomStalker **робить:** допомагає тобі спілкуватися, пам'ятає людей, яких ти
*сам* додав, а згодом — перевірятиме *твій власний* цифровий слід.

PhantomStalker **не робить (жорсткі межі):**

- не збирає й не агрегує інформацію про третіх осіб;
- не має «пошуку людей» чи OSINT по чужих — CRM лише з ручним введенням;
- self-footprint (v0.2) — тільки після підтвердження, що адреса/нік належать тобі,
  і з екраном згоди;
- жодного масового розсилання, спаму чи автоматичних дій від чужого імені.

## Дорожня карта

- **v0.1 (зараз):** персонаж + головний TUI, ко-пілот листування зі стрімінгом,
  базова CRM з нагадуваннями, локальна SQLite, налаштування з keyring.

- **Пізніше:** опційні інтеграції месенджерів (лише чернетки відповідей), теми оформлення, плагіни.
