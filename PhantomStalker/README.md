# 👻 PhantomStalker

> **Твій фантом. Твої люди. Твій слід.**

PhantomStalker — термінальний застосунок-компаньйон з ШІ-персонажем: маленьким
оранжевим фантомом, який живе у твоєму терміналі й допомагає тобі спілкуватися з
людьми, тримати стосунки в порядку й стежити за *власним* цифровим слідом —
тепло, стильно й приватно.

```
╭──────────────────────────────────────────────────────────╮
│     .---.   PhantomStalker v0.1.0                         │
│    ( o o )  Твій фантом. Твої люди. Твій слід.            │
│    |  ‿  |                                                │
│    |     |  /help — команди   @ім'я — нотатки про людину  │
│    '^'^'^'  ~/.phantomstalker/phantom.db                  │
╰──────────────────────────────────────────────────────────╯

● Знову разом! Що пишемо?
  Давно не було зв'язку: Олена (32 дн.) — може, написати?

> напиши @Олена що я давно не писав і кличу на каву

● Привіт, Олено! Вибач, що так довго мовчу 🙈 Може, вип'ємо кави в суботу?

> /add Максим @max #робота колега, бекенд

● Додано
  ⎿  Максим · @max · #робота

(^ ^) Phantom  Запам'ятав: Максим.
╭──────────────────────────────────────────────────────────╮
│ > /sh                                                     │
╰──────────────────────────────────────────────────────────╯
  /shorter [текст]   зробити коротше
  /show <ім'я>       картка людини
```

Жодних вкладок, кнопок і панелей — одна стрічка розмови й поле `>` унизу,
як у консольних ШІ-агентах. Просто пиши фантому, а дії викликай slash-командами.

## Можливості (v0.1)

- **Фантом.** Мордочка в рядку статусу над полем вводу живе своїм життям:
  `(o o)` idle · `(o O)` thinking · `(^ ^)` happy · `(O O)` alert · `(- -)` sleeping.
  Коротко реагує на твої дії, засинає без активності, прокидається від клавіш.
- **Розмова.** Пиши звичайним текстом — фантом відповідає зі стрімінгом і пам'ятає
  контекст сесії. `@Олена` у повідомленні додає до запиту твої нотатки про цю людину
  (лише коли ти її згадав).
- **Ко-пілот листування.** `/polish`, `/warmer`, `/formal`, `/shorter`,
  `/translate <мова>`, `/reply <повідомлення>`. Без тексту команда бере останню
  відповідь фантома, тож можна ланцюжком: `/warmer` → `/shorter` → `/translate англійська`.
- **Особиста CRM** (тільки ручне введення): `/add`, `/people`, `/show`, `/note`,
  `/met`, `/date`, `/rm`, `/remind`. На старті фантом нагадує про найближчу
  дату або людину, з якою давно не було зв'язку.
- **Налаштування командами:** `/name`, `/tone`, `/model`, `/key`.

## Встановлення

Потрібен Python 3.11+.

```bash
cd PhantomStalker
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
```

## Ключ API

Отримай ключ на [platform.claude.com](https://platform.claude.com/) і обери один спосіб:

1. **Рекомендовано:** запусти застосунок, введи `/key` і встав ключ (він приховується
   при вводі й не потрапляє в стрічку чи історію). Ключ збережеться в системному keyring
   (macOS Keychain, Windows Credential Locker, Secret Service у Linux).
2. Або скопіюй `.env.example` у `.env` і впиши `ANTHROPIC_API_KEY=...`
   (зручно на серверах без keyring). `.env` вже в `.gitignore`.

Порядок пошуку ключа: keyring → змінна середовища `ANTHROPIC_API_KEY`.

## Запуск

```bash
phantomstalker              # або: python -m phantomstalker
phantomstalker --db ./my.db # інша база
```

База за замовчуванням: `~/.phantomstalker/phantom.db` (або `$PHANTOMSTALKER_DB`).

### Команди

| Команда | Дія |
|---|---|
| *просто текст* | розмова з фантомом (`@ім'я` — додати нотатки про людину) |
| `/polish` `/warmer` `/formal` `/shorter` `[текст]` | переписати текст (або останню відповідь) |
| `/translate <мова> [текст]` | перекласти |
| `/reply <повідомлення>` | запропонувати відповідь на отримане |
| `/add Олена Петренко @olena #друзі любить каву` | додати людину (нік, теги, нотатки) |
| `/people [пошук]` · `/show <ім'я>` | список · картка |
| `/note <ім'я> <текст>` | дописати нотатку |
| `/met <ім'я> [про що]` | відмітити розмову |
| `/date <ім'я> 14.03 День народження` | важлива дата (щорічно) |
| `/rm <ім'я>` | видалити (з підтвердженням) |
| `/remind` | нагадування |
| `/name` · `/tone` · `/model` · `/key` | налаштування |
| `/clear` · `/help` · `/exit` | очистити · довідка · вихід |

### Клавіші

`Tab` — доповнити команду · `↑`/`↓` — історія (або вибір підказки) ·
`Esc` — перервати відповідь / скасувати · `Ctrl+C` — очистити рядок, на порожньому — вихід.

## Архітектура

```
UI (Textual: стрічка, рядок статусу, поле вводу)
 └─ Core (PersonaEngine, CommandProcessor — slash-команди без прив'язки до UI)
     └─ Services (CopilotService → Claude API, CRMRepository, SettingsService)
         └─ Storage (SQLite + keyring)
```

Потік: дія користувача → App → потрібний сервіс → оновлення стану → ререндер UI + реакція фантома.

```
src/phantomstalker/
├── __main__.py            # CLI-вхід
├── app.py                 # консоль: ввід, історія, стрімінг, підтвердження
├── core/
│   ├── persona.py         # настрої, ASCII-фантом, мордочки, репліки, анімація
│   └── commands.py        # slash-команди, розбір аргументів, @згадки
├── services/
│   ├── copilot.py         # промпти + стрімінг через anthropic SDK
│   ├── crm.py             # контакти, взаємодії, важливі дати, нагадування, чернетки
│   └── settings.py        # налаштування в SQLite, ключ API в keyring, .env
├── storage/db.py          # схема SQLite
└── ui/console.py          # рендер записів (●, ⎿), статус, підказки команд
```

**Таблиці БД:** `contacts`, `interactions`, `important_dates`, `drafts`,
`footprint_checks` (лише self, зберігається хеш), `settings`, `persona_state`.

### Claude API

Ко-пілот використовує офіційний `anthropic` SDK зі стрімінгом і моделлю
`claude-opus-5-5` (змінюється через `/model`). Для швидкості працює з `effort: low`. Увімкнено серверний fallback (`fallbacks: "default"`):
якщо модель відхилить запит, API саме перезапустить його на відповідній моделі.
Якщо відмова все ж трапилась — фантом переходить у стан `alert` і повідомляє про це.

## Приватність і етичні межі

**Усе локально.** База живе на твоїй машині; назовні йде лише текст, який ти
свідомо надсилаєш у Claude API. Ключ API — у keyring, а не в коді чи базі.

PhantomStalker **робить:** допомагає тобі спілкуватися, пам'ятає людей, яких ти
*сам* додав, а згодом — перевірятиме *твій власний* цифровий слід.

PhantomStalker **не робить (жорсткі межі):**

- не збирає й не агрегує інформацію про третіх осіб;
- не має «пошуку людей» чи OSINT по чужих — CRM лише з ручним введенням;
- self-footprint (v0.2) — тільки після підтвердження, що адреса/нік належать тобі,
  і з екраном згоди;
- жодного масового розсилання, спаму чи автоматичних дій від чужого імені.

## Дорожня карта

- **v0.1 (зараз):** консоль з фантомом, розмова й ко-пілот листування зі стрімінгом,
  базова CRM з нагадуваннями, локальна SQLite, ключ у keyring.
- **v0.2:** `/footprint` — self-footprint (HaveIBeenPwned) з підтвердженням власності, кастомізація
  персонажа, експорт і бекап, шифрування чутливих полів (Fernet / SQLCipher).
- **v0.3:** `/coach` — підготовка до розмов, щоденник взаємодій, AI-теми для розмови, розумні нагадування.
- **Пізніше:** опційні інтеграції месенджерів (лише чернетки відповідей), теми оформлення, плагіни.
